# 01 · 环境搭建

目标：**三条命令跑起来**。跑不起来时先翻这一篇，还不行就查 [02-报错急救表](02-报错急救表.md)。

## 你需要什么

| 必须 | 说明 |
|---|---|
| Windows 10/11（或 macOS / Linux） | 主路径是 Windows；另外两个平台见下面「CMake 那条路」 |
| **Visual Studio 2022**，或 **MinGW g++** | 二选一。VS 装社区版即可，工作负载勾「**使用 C++ 的桌面开发**」 |

**不需要**：显卡、显卡驱动、引擎、包管理器、Python、联网。
这是个纯 CPU 的软件渲染器，机房的老机器、远程桌面、虚拟机里都能跑。

> **Python 只有一种情况需要**：你想重跑 `tools/` 里的工具（重新烘焙字模、或做 PNG 逐像素比对）。
> 玩和改都不用。PNG 比对那个还需要 Pillow（`python -m pip install pillow`）。

## 三条命令

```bash
git clone -b digitalmedia https://github.com/sykesP42/CS-TriadLect.git dreamlab-rt && cd dreamlab-rt
./build.bat                        # 编译。Linux / macOS 用 ./build.sh
build\dreamlab.exe                 # 开玩。也可以直接双击 run.bat
```

> `-b digitalmedia` 不能省：这个仓库的默认分支放的是别的课程内容。末尾的
> `dreamlab-rt` 是给克隆下来的文件夹起名，后面那条 `cd dreamlab-rt` 才成立。

**编译大概十几秒**。成功的话最后一行是：

```
[build] ok: build\dreamlab.exe
```

## 跑起来应该看到什么

**一间全黑的屋子。这是对的，不是出错。**

那是第 0 关「黑暗」本身 —— 这游戏就从"一片黑暗"开始。你能看见的只有：

- 画面正前方一小片地板（你身上的微光）
- 远处桌子上终端屏幕的一点青蓝色光
- 左上角的中文面板：「第 0 关 · 黑暗 / 目标：让房间重新亮起来 / 进度 0%」

跟着终端走，走到桌子前按 `E`，它会告诉你该改哪个文件。

## build.bat 是怎么找到编译器的

按这个顺序试，第一个能用就用：

1. 你已经在「Developer Command Prompt for VS」之类的开发环境里（`cl` 直接可用）
2. 用 `vswhere` 自动找到最新的 Visual Studio，调它的 `vcvars64.bat`
3. 找 MinGW 的 `g++`

三个都不行会打印一段提示，告诉你装什么。**这一步不需要你手动配任何环境变量** ——
在普通的 cmd 或双击里跑就行。

## 三条构建路径

| 路径 | 命令 | 什么时候用 |
|---|---|---|
| **主路径** | `./build.bat`（Windows）<br>`./build.sh`（Linux / macOS / Git Bash） | 默认用这个 |
| **CMake** | `cmake -B build-cmake && cmake --build build-cmake --config Release` | `build.bat` 探测不到工具链时；macOS / Linux 上更顺手 |

CMake 那条路有两个坑，都是踩过的：

- **一定要带 `--config Release`。** 不加的话 VS 生成器会去构建没有优化的 Debug ——
  一个软光栅化实时渲染器跑未优化版本，帧率会差好几倍。
- **构建目录必须留在仓库内**（用 `build-cmake/` 就好）。程序启动时会从 exe 所在目录
  **往上找 3 级**去定位仓库根（好找到 `assets/` 和 `content/`）；把构建目录摆到仓库外面
  就找不着了。

> CMake 不用另装：装了 Visual Studio 2022 就自带（`cmake` 和 `ninja` 都在）。
> 构建日志里会出现一条 `'pwsh.exe' 不是内部或外部命令` —— 那是 CMake 自己的行为，
> 任何 CMake 工程在这台机器上都会报，无害，构建照常成功。

## 验证装好了没有

```bash
build\dreamlab.exe --selftest      # 应该打印：315 项检查全部通过
```

这条会跑一遍数学、光栅化、字模、碰撞、数据解析、四个关卡的判定 —— 全过就说明
这台机器上一切正常。

## 想直接看一张图（不开窗）

```bash
build\dreamlab.exe --shot build\out.png --level 3 --width 960 --height 540
```

不开窗口，渲完写一张 PNG。脚本、验收、没有桌面环境（比如 SSH 进去）都靠它。
