# ============================================================================
#  贴图设置 —— 数媒组工作室的地板
# ----------------------------------------------------------------------------
#  改这里，存盘，回到游戏里按 R，立刻生效：不用重启，不用重新编译。
#
#  先知道一件事：这个仓库里没有一张图片素材。地板上的方格砖是代码现画出来的
#  —— 一张 128x128 的图，画了 4x4 个方块，一亮一暗。程序把这张图"贴"到地板上，
#  而"怎么贴"就是下面三个词。技术美术每天在引擎里打交道的，就是这三个词。
#
#  参数含义：
#    uvscale <横> <竖>   一张贴图在地板上铺几次。
#                        1 1 = 整块地板只铺一张（图里的 4x4 个方块直接拉满地板，
#                              每块 1.5 米 —— 一眼看出被拉伸了）；
#                        4 4 = 横竖各铺 4 张 = 16 个格子，每块 0.75 米，像地砖。
#    wrap repeat|clamp  贴图用超了（比如平铺 4 张，可坐标只有 0~1）怎么办。
#                        repeat = 超出去的部分从头再来，也就是"平铺"；
#                        clamp  = 不要新格子，把边缘那一条颜色拉出去 ——
#                                 铺超过一张时，整块地板会变成一个纯色。
#    filter nearest|bilinear
#                        一个像素问贴图"你是什么颜色"，贴图怎么答。
#                        nearest  = 取最近的那一个像素。格线硬，远处会一格一格地闪；
#                        bilinear = 把周围四个像素插值一次。近了柔和，远处也不闪。
#
#  现在这三项被人调乱了（下面每一行后面有标注）。这间屋子的地板本该是一块一块
#  铺满的方格砖：平铺 4x4、repeat、bilinear。三件事各占进度条的 40% / 30% / 30%。
#
#  上手就试（改完存盘 → 切回游戏按 R）：
#    · uvscale 先改成 4 4 —— 会看到平铺立刻生效（或者变纯色，看下面那条）
#    · wrap 从 clamp 改成 repeat —— 纯色会"啪"地变回格子
#    · filter 在 nearest / bilinear 之间来回换 —— 盯远处的地板看
# ============================================================================

material floor {
    albedo    1.00 1.00 1.00        # 给贴图乘的颜色，白色 = 贴图原样显示
    roughness 0.30                  # 有点反光的地砖（不是镜面，也不是哑光）

    uvscale   1 1                   # ← 被调乱了：该是 4 4（现在就铺了一张，格子老大）
    wrap      clamp                 # ← 被调乱了：该是 repeat（超出去的部分没从头再来）
    filter    nearest               # ← 被调乱了：该是 bilinear（现在采样只取最近一个像素）
}
