# ============================================================================
#  灯 —— 数媒组工作室
# ----------------------------------------------------------------------------
#  改这里，存盘，回到游戏里按 R，立刻生效。（和 materials.txt 同一套语法。）
#
#  一盏灯有四个参数，四个都是能改的：
#    pos       位置：三个数 = x y z（米）。房间以中心为原点，地板是 y=0，
#              天花板 y=3.4。出生点在 (0, 0, 4.5)，桌子在 z=-5 那边。
#              改它 = 把灯吊到别处去，地上的光斑会跟着走。
#    color     颜色：三个数 = 红 绿 蓝，可以超过 1（那会更亮、更偏色）。
#    intensity 强度：0 = 关着。光的亮度按距离平方衰减 —— 距离翻一倍，
#              亮度只剩四分之一。所以位置比强度重要得多，先摆位置再拧强度。
#    radius    灯的物理尺寸（米）：0.05 是一颗灯泡（高光是个小点），
#              0.9 是一整块发光面板（高光是柔和的一大片）。
#
#  在游戏里查当前的灯：敲 light 这个命令（不带参数），每盏灯的位置和强度都会打出来。
#
#  上手就试（改完存盘 → 切回游戏按 R）：
#    · 把 light 0 的 pos 的 y 从 2.90 改成 1.20 → 主光落到和展台一样高，
#      球的下半截亮、上半截黑（这就是"位置比强度重要"）
#    · 把 light 0 的 color 改成 1.0 0.6 0.3 → 白光变暖橙，整间屋子变黄昏
#    · 把 light 1 的 intensity 改成 0 → 冷色补光关掉，暗部直接沉进纯黑
# ============================================================================

# ---- 主光：吊灯 ------------------------------------------------------------
# 灯罩本体挂在 (2.2, 2.9, 1.2)：桌子右上方、离天花板 0.5 米。
# 注意「灯」和「灯罩」是两个东西：灯罩是 material lamp 那个会发光的方块，
# 这盏灯是照亮别人的东西。位置要一致 —— 不然会出现"灯罩挂在天上、
# 光却打在别处"这种一眼假的画面。
#
# 而现在就是这样：搬器材的时候灯的位置参数被改乱了，光被留在了门口。
# 灯罩本身也还暗着（content/materials.txt 里 material lamp）。
light 0 {
    pos       0.00 1.10 4.60       # ← 被留在门口了（吊灯挂在 2.20 2.90 1.20）
    color     1.00 0.93 0.82
    intensity 0                    # 0 = 关着
    radius    0.9
}

# ---- 补光：冷色，从左边打过来，负责把暗部从纯黑里拉回来 --------------------
# 它还是关着的：一盏灯一盏灯来，先把主光弄明白。
light 1 {
    pos       -4.20 2.60 1.60
    color     0.45 0.62 1.00
    intensity 0
    radius    0.45
}
